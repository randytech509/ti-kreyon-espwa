# Kreyòl translation bundle — Ti kreyon espwa

Source: `index.html` (English). 152 segments, ~1 200 words. Paste the block below into the
translator, then fill the third column. Keep the numbering: the translated file is re-injected
into a dedicated `/ht/` page by matching these numbers.

## Prompt to give the translator

> You are translating the website of **Ti kreyon espwa**, a Haitian NGO that supports vulnerable
> children in Haiti with school supplies, hot meals and creative workshops. Translate from English
> into **Haitian Creole (Kreyòl ayisyen)**, using the official IPN/Akademi Kreyòl Ayisyen
> orthography.
>
> This is public-facing copy for donors, partners and Haitian families — not a legal document.
> Translate the **meaning and the warmth**, not the words. Short, spoken, dignified Kreyòl that a
> parent in Haiti reads without effort. Avoid francisms and calques from English; if a literal
> translation sounds like translated text, rewrite it.
>
> Rules:
> 1. Return the same table, same numbers, one translation per row. Never merge or drop a row.
> 2. Keep these **untranslated, spelled exactly as written**: Ti kreyon espwa · Sak Lekòl ·
>    Vant Plen · PayPal · WhatsApp · Facebook · Instagram · Formspree · USD ·
>    administration@tikreyonespwa.org · +1 407 664 0650
> 3. Keep the punctuation style (em dashes, question marks) and any `*` marker.
> 4. Rows that are single words (menu items, buttons) must stay short — they sit in a navigation
>    bar and a long label breaks the layout.
> 5. Where English uses "children", prefer *timoun*; for "school kit", *sak lekòl*; the motto
>    "Every child has a beautiful story to write" already exists in Kreyòl as
>    *« Chak timoun gen yon bèl istwa pou l ekri »* — reuse it verbatim.
